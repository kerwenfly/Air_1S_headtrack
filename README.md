# headtrack — Rayneo Air 1s 头追程序

读取雷鸟 Air 1s 眼镜的内置 IMU，既可以把头部转动注入为鼠标相对位移（用「转头」控制光标），
也可以模拟 NS Pro 手柄的姿态传感器、用 DSU（cemuhook UDP）协议把运动数据推送给模拟器。
带 GUI，可切换模拟设备并调整各自参数，设置自动保存。

底层 HID 通信、姿态融合、鼠标注入与 DSU 服务端逻辑复用共享包 [`../imutool/glass`](../imutool/glass)，
本模块只负责界面、参数热更新与会话管理。

## 功能

- 设备状态实时显示，未检测到眼镜时「启动」按钮置灰不可点
- 「启动 / 停止」按钮随运行状态动态切换文案
- 「模拟设备」下拉框切换两种工作模式：
  - **鼠标**：灵敏度、死区用滑块调节，拖动过程中即时生效，另有反转 X / Y 轴复选框
  - **NS Pro 手柄（DSU）**：监听端口、槽位可配置，陀螺三轴与加速度三轴可分别取反
- 「复位视角」按钮，等价于热键 `Ctrl+Alt+R`（仅鼠标模式）
- 点击标题栏最小化按钮收进系统托盘；托盘图标单击可恢复窗口
- 设置自动保存到可执行文件同目录的 `headtrack.json`，下次启动自动加载

## 环境要求

- Windows 10 及以上（依赖 HID、`SendInput`、托盘等 Win32 接口）
- Go 1.25 或更高版本
- 雷鸟 Air 1s 眼镜，通过 USB 连接（`VID_1BBB` / `PID_AF50`）

### 运行前提

1. 若需要用头追操作一个**以管理员身份运行**的目标程序，本程序也必须以管理员身份启动，
   否则注入的鼠标事件会被 UIPI 拦截。
2. 启动后请保持眼镜静止约 **3.3 秒**（1500 帧 @ 约 460Hz），等待陀螺零偏校准完成。
   校准完成前两种模式都不输出：鼠标模式不接管鼠标，DSU 模式不推送数据
   （否则模拟器会看到「静止却持续旋转」，并据此污染其内部姿态基准）。

## 使用

双击 `headtrack.exe` 即会弹出主界面。

| 区域 | 内容 |
| --- | --- |
| 状态 | 设备连接情况、运行/校准状态、姿态 yaw/pitch（鼠标）或订阅者/帧数（DSU）、操作提示 |
| 控制参数 | 顶部「模拟设备」下拉框；下方随所选设备显示对应参数 |
| 按钮 | 启动（运行中变为停止）、复位视角、最小化到托盘 |

### 鼠标模式

- **灵敏度**：1–300 像素/度。值越大，同样的转头角度光标移动越多。
- **死区**：0–30 度（步长 0.1）。头部相对中位的偏差小于该角度时不移动光标，
  用于过滤微小手抖；采用软死区（`offset = sign(d)·max(0, |d| − deadzone)`），
  边界处连续，不会出现突然跳动。
- **复位视角**（`Ctrl+Alt+R`）：把当前姿态设为角度中位并清零累计位移。
  yaw 依赖陀螺积分、会缓慢漂移，需要时可重新复位纠正。

### DSU 模式（模拟 NS Pro 手柄姿态传感器）

以 cemuhook UDP 协议（DSU v1001）在回环地址上提供运动数据，模拟器把它当作带完整陀螺仪的
手柄读取。已确认 Eden 模拟器支持该方式（官方 `docs/user/GyroControls.md` 使用
`engine:cemuhookudp`）。

- **监听端口**：默认 `26760`，与 cemuhook 约定一致，一般无需修改。
- **槽位（1~4）**：对应模拟器中的 `pad:0`~`pad:3`。默认槽位 1 ↔ `pad:0`。
- **陀螺取反 / 加速度取反**：程序已把陀螺与加速度**一起**换算到 NS Pro 的报文轴向约定
  （整体绕 X 轴 180°，即 Y 轴与 Z 轴取反）。协议要求陀螺与加速度处于同一机体坐标系，
  Eden 正是按 NS Pro 原生数据解算，因此默认全部不勾选即为正确方向。
  仅当模拟器中仍有方向不符（例如抬头变成低头、左转变成右转）时，才勾选对应轴微调，运行中即时生效。
- 该模式下不使用姿态解算，直接推送**已减陀螺零偏**的原始角速度（deg/s）与加速度（g），
  因此不会累积姿态漂移，也无需「复位视角」。

配置完点击「启动」后，状态行会显示订阅者数量；模拟器开始读取后订阅者变为 1。

#### Eden 配置

编辑 `%APPDATA%\eden\config\qt-config.ini`，把运动输入指向本程序（端口与界面一致）：

```ini
player_0_motionleft="motion:0,pad:0,port:26760,guid:0000000000000000000000007f000001,engine:cemuhookudp"
player_0_motionright="motion:0,pad:0,port:26760,guid:0000000000000000000000007f000001,engine:cemuhookudp"
```

`guid` 中的 `7f000001` 即回环地址 `127.0.0.1`。配置后重启 Eden，在控制器设置里确认
运动来源为 cemuhook 且能看到陀螺数据。

### 设置文件

参数变更后延迟 300ms 写入 `headtrack.json`（与 exe 同目录，便于整包拷贝迁移），
窗口关闭时再兜底保存一次。文件缺失或损坏会自动回退到默认值。

```json
{
  "device": "mouse",
  "deadzone_deg": 1,
  "sensitivity": 20,
  "invert_x": false,
  "invert_y": false,
  "dsu": {
    "port": 26760,
    "slot": 1,
    "invert_gyro": [false, false, false],
    "invert_accel": [false, false, false]
  }
}
```

`device` 为 `mouse` 或 `dsu`；切换模拟设备后重新「启动」才会按新模式运行。

## 工作原理

1. 打开眼镜 HID 接口，下发 `SensorOutputOn`（`0x01`）启用传感器推送。
2. 逐帧解析 65 字节输入报文（帧头 `0x99`、IMU 载荷 `0x65`），得到角速度、加速度与时间戳。
3. 连续静止累计 1500 帧后取角速度均值作为陀螺零偏；期间任一轴偏离均值超过阈值即整体重来。
   零偏校准对两种模式都生效，且**校准完成前不输出**（期间界面状态行会显示校准进度）。

之后按所选模拟设备分流：

**鼠标模式**

4. 减去零偏后送入 Mahony 互补滤波（Kp=0.5、Ki=0.02）融合出姿态四元数，
   采样间隔优先取报文时间戳差分，异常时回退到 460Hz。
5. 取机体系 +Z 轴在世界系的朝向，与复位时记录的中位比较得到 yaw/pitch 偏差；
   yaw 按最小路径做角度解缠后累计，跨 ±180° 不跳变。
6. 累计偏差经软死区与灵敏度换算为目标累计像素偏移，本帧位移 = 目标偏移 − 已发出偏移，
   通过 `SendInput` + `MOUSEEVENTF_MOVE` 注入。因为是相对位移注入，
   **注入量与物理鼠标的移动自然叠加，物理鼠标可照常使用**。

**DSU 模式**

4. 不做姿态解算：把减去零偏的角速度由 rad/s 换算为 deg/s、加速度由 m/s² 换算为 g，
   按界面取反设置后写入 100 字节控制器数据包（时间戳由报文的 100µs 单位换算为 µs）。
5. 报文为 16 字节头（`DSUS` + 版本 1001 + 长度 + CRC32 + 发送方标识）+ 4 字节消息类型 + 载荷，
   仅运动数据为实测值，按键与摇杆填中性值，避免覆盖用户在模拟器中映射的按键。
6. 服务端在回环 `127.0.0.1:<端口>` 监听，应答模拟器的版本查询、控制器信息查询与数据订阅；
   订阅有效期 5 秒，模拟器每 3 秒续订一次，超过 5 秒未续订即停止向其推送。

## 常见问题

- **提示「未找到眼镜设备」**：确认 USB 已连接、官方 Mirror Studio 已关闭；可先跑 `imutool probe`。
- **转头时光标不动 / 方向相反**：确认已过零偏校准（状态行不再显示「校准中」）；
  方向不对时勾选「反转 X 轴」或「反转 Y 轴」。
- **DSU 模式下状态行一直显示「订阅者 0」**：确认模拟器已启用 cemuhook 运动输入且端口与界面一致；
  Eden 需重启后配置才生效。可先用 `imutool dsu` 单独验证服务端，再用抓包或 Eden 日志确认订阅到达。
- **DSU 模式下游戏内转头方向相反**：勾选「陀螺取反」或「加速度取反」中对应的轴，运行中即时生效。
- **DSU 模式启动失败、提示端口被占用**：`26760` 已被其它 DSU 服务端（如 BetterJoy、DS4Windows）占用，
  关闭它们或在界面中改端口（同时修改模拟器配置）。
- **目标程序里无效**：目标程序若以管理员身份运行，请以管理员身份启动本程序。
- **光标缓慢漂移**：yaw 只能靠陀螺积分、无法被加速度计观测，属固有漂移，按 `Ctrl+Alt+R` 复位即可。
